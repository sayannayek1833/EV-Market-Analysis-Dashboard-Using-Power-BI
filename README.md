# EV-Market-Analysis-Dashboard
Power BI dashboard analyzing 177k+ electric vehicles, highlighting BEV dominance, Tesla’s 45% market share, geographic hotspots like King County, and the impact of CAFV incentives. Includes insights on top EV models, adoption trends, and data-driven patterns shaping the EV market.
Dataset Link : https://catalog.data.gov/dataset/electric-vehicle-population-data
